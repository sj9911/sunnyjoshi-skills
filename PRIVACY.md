# Privacy Policy

Effective date: 29 September 2026

SunnyJoshi Humanizer is a skills-only plugin. It provides writing instructions to ChatGPT and Codex and does not operate an external server.

## Data collected

The plugin developer does not collect personal data, account information, prompts, uploaded files, rewritten text, analytics, or usage logs through this plugin.

## How data is used

Because the plugin developer does not receive personal data through the plugin, the developer does not use it for advertising, profiling, model training, or any other purpose. Text is processed within the OpenAI product where the plugin is used, subject to OpenAI's applicable privacy terms and user settings.

## Data sharing

The plugin does not send data to the developer or to third-party services. The developer therefore does not sell or share plugin data.

## Data retention

The plugin developer retains no prompts, files, outputs, or user data because none is received. Data retained by OpenAI is governed by OpenAI's policies and the user's account or workspace settings.

## User controls

Users can disable or uninstall the plugin at any time. Users can also manage their data and privacy settings through the OpenAI product in which they use the plugin.

## Changes

Material changes to this policy will be published in this repository with a revised effective date.

## Contact

For privacy questions, email thesunnyjoshi@gmail.com or open an issue at https://github.com/sj9911/sunnyjoshi-skills/issues.
